# Astarte Typing

Astarte 配列を少し変えた配列（Astarte 改）を練習するための Web タイピングアプリ。
OS のキー配列は QWERTY のままで、アプリ側で物理キー位置を配列の文字に変換します。

▶ https://shiryu2002.github.io/astarte-typing/

```
Q P U Y , J D H G W
I O E A . K T N S R
Z X C V ; M L F B /
```

## 機能

- 画面上にキーボードを常時表示。次に打つキーをハイライト（Shift が要るときは反対の手の Shift も光る）
- QWERTY の元キーを副ラベル表示（切替可）、指ごとの色分け（切替可）
- モード
  - レッスン（段階ドリル）: ホーム段 → +上段 → +下段 → 全アルファベット。英単語 / 日本語ローマ字を選択
  - 英単語 / 英文
  - 日本語 単語 / 文（ローマ字入力。si/shi、tu/tsu、n/nn などの表記ゆれを受理）
- エンドレスモード（既定）: お題が尽きても続く。`Esc` で終了して結果を見る
- KPM・正確率・ミス数の計測、苦手キーの表示、モード別自己ベスト（localStorage）
- 配列を画面上で編集して別の配列も練習可能

## 使い方

- IME をオフ（半角英数）にして、物理 QWERTY の位置でキーを押す
- 間違えると進まないので、正しいキーを押し直す
- `Enter`: 新しいお題 / `Esc`: やり直し（エンドレス中は終了して結果表示）

## ローカル実行

ES modules を使っているので、ファイル直開きではなく HTTP サーバー経由で開く。

```sh
python3 -m http.server 8000
# http://localhost:8000/
```

## 構成

| ファイル | 役割 |
| --- | --- |
| `js/layout.js` | 配列定義、物理キー → 文字の変換（純粋関数） |
| `js/romaji.js` | ひらがな → ローマ字入力の判定エンジン |
| `js/targets.js` | お題1件の入力判定インターフェース（英文 / ローマ字） |
| `js/lessons.js` | 段階ドリルのお題生成 |
| `js/stats.js` | 計測と自己ベスト保存 |
| `js/keyboard.js` | 画面キーボードの描画とハイライト |
| `js/main.js` | 状態管理と UI 配線 |
| `js/corpus/` | 単語・文のデータ |
